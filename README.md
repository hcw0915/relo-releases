# Relo — Android APK downloads

Official Android APK builds of **Relo**, the personal relationship notebook app (Taiwan).

- Website: https://getrelo.app
- Download the latest version: see [Releases](https://github.com/hcw0915/relo-releases/releases/latest), or scan the QR code at https://getrelo.app

Each release contains a signed APK (`relo-<version>.apk`) and its SHA-256 checksum.
Only install APKs from this repository or from getrelo.app.
